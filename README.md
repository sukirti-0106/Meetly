# Meetly 🎥💬

**Meetly** is a modern, real-time video conferencing web application designed for seamless collaboration and instant communication. Built with high performance and user privacy in mind, Meetly allows teams, educators, and friends to connect via high-quality video, audio, and secure text chat directly through their browsers.

## 🚀 Key Features

* **Real-Time Video & Audio:** High-quality, low-latency communication powered by WebRTC.
* **Instant Room Creation:** Generate unique, secure room links instantly without tedious setup.
* **Screen Sharing:** Share presentations, documents, or entire screens with a single click.
* **In-Meeting Chat:** Send text messages and share links during live calls.
* **Responsive Design:** Optimized for a seamless experience across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

* **Frontend:** React.js / Next.js, Tailwind CSS
* **Backend:** Node.js, Express
* **Real-Time Communication:** WebRTC, Socket.io
* **Hosting/Deployment:** Vercel (Frontend), Render / AWS (Backend)
